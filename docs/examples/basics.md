# 基本構文

> このCコードは、altcの意味とコストモデルを説明するために推定した非規範的なlowering例です。実装はこの出力形式、内部名、helper、制御構造、最適化、コメント位置、翻訳単位構成を模倣してはならず、Draft規範仕様を満たす別のC11生成を選べます。

関連仕様：[字句構造](../spec/lexical-structure.md)、[宣言](../spec/declarations-and-modules.md)、[式](../spec/expressions-and-control-flow.md)

## altc

```altc
/// valueを0以上Limit以下へ収める。
const Limit: i32 = 100;

fn clamp(value: i32) -> i32 {
  if value < 0 {
    0
  } else if value > Limit {
    Limit
  } else {
    value
  }
}

fn classify(value: i32) -> i32 {
  let base: i32 = {
    let adjusted = clamp(value);
    adjusted + 1
  };

  let mut result: i32 = 0;
  result = if base >= 50 { 1 } else { -1 };
  return result;
}

@entry
fn main() -> c_int {
  // assignmentはunitを返すが、格納結果はresultから読める。
  classify(75) as c_int
}
```

## 取り得るC11

```c
/* Generated by altc. Do not edit. */
#include <stdint.h>

/* valueを0以上Limit以下へ収める。 */
static const int32_t Limit = INT32_C(100);

static int32_t clamp(int32_t value) {
  int32_t if_result;
  if (value < INT32_C(0)) {
    if_result = INT32_C(0);
  } else if (value > Limit) {
    if_result = Limit;
  } else {
    if_result = value;
  }
  return if_result;
}

static int32_t classify(int32_t value) {
  int32_t adjusted = clamp(value);
  int32_t base = adjusted + INT32_C(1);
  int32_t result = INT32_C(0);

  int32_t if_result;
  if (base >= INT32_C(50)) {
    if_result = INT32_C(1);
  } else {
    if_result = -INT32_C(1);
  }
  result = if_result;
  return result;
}

int main(void) {
  return (int)classify(INT32_C(75));
}
```

## 対応の要点

- doc commentをC commentへ残すかは非規範的で、HTML docとの対応が規範です。
- block式と`if`式をtemporaryへ置く形は一例です。C functionへ分ける、branch先で直接returnする変換も可能です。
- `result = ...`の値は`unit`なので、C assignment expressionのreturn valueには依存しません。
- `as c_int`は明示変換です。`i32`とCの`int`を自動的に同一視しません。
- `@entry`によって、このaltc functionからC ABIの`main(void)`が生成されます。
