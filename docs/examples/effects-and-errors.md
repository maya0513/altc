# Effectとerror

> このCコードは、altcの意味とコストモデルを説明するために推定した非規範的なlowering例です。実装はこの出力形式、内部名、helper、制御構造、最適化、コメント位置、翻訳単位構成を模倣してはならず、Draft規範仕様を満たす別のC11生成を選べます。

関連仕様：[effect、memory access、error](../spec/memory-effects-and-errors.md)、[C ABI公開](../spec/c-interop.md#c-abi公開とheader生成)

## altc

```altc
extern "C" from <stdlib.h> {
  fn malloc(size: usize) -> ?*mut unit with { alloc };
  fn free(pointer: *mut unit) with { free };
}

enum ParseError {
  Empty,
  Invalid,
}

@repr(C)
pub enum LoadError {
  Allocation,
  Empty,
  Invalid,
}

fn parse_byte(data: *const u8, len: usize) -> i32
    with { raise[ParseError] } {
  if len == 0 {
    raise ParseError::Empty;
  }
  let value: u8 = *data;
  if value > 9u8 {
    raise ParseError::Invalid;
  }
  value as i32
}

@c_name("load_value")
export "C" fn load(input: u8) -> i32
    with { alloc, free, raise[LoadError] } {
  let raw = malloc(1);
  let buffer: *mut u8 = match raw {
    nonnull(pointer) => ptr_cast[u8](pointer),
    null => raise LoadError::Allocation,
  };

  defer {
    free(ptr_cast[unit](buffer));
  }

  *buffer = input;
  try {
    parse_byte(buffer, 1)?
  } catch {
    ParseError::Empty => raise LoadError::Empty,
    ParseError::Invalid => raise LoadError::Invalid,
  }
}
```

## 取り得るC11

```c
/* Generated by altc. Do not edit. */
#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>

typedef enum ParseError {
  ParseError_Empty,
  ParseError_Invalid
} ParseError;

typedef enum LoadError {
  LoadError_Allocation,
  LoadError_Empty,
  LoadError_Invalid
} LoadError;

static int32_t parse_byte(
    const uint8_t *data,
    size_t len,
    int32_t *out_value,
    ParseError *out_error) {
  if (len == 0u) {
    *out_error = ParseError_Empty;
    return 1;
  }
  uint8_t value = *data;
  if (value > UINT8_C(9)) {
    *out_error = ParseError_Invalid;
    return 1;
  }
  *out_value = (int32_t)value;
  return 0;
}

int32_t load_value(
    uint8_t input,
    int32_t *out_value,
    LoadError *out_error) {
  uint8_t *buffer = (uint8_t *)malloc(1u);
  int32_t status;
  int32_t parsed = INT32_C(0);
  ParseError parse_error = ParseError_Empty;

  if (buffer == NULL) {
    *out_error = LoadError_Allocation;
    return 1;
  }

  *buffer = input;
  status = parse_byte(buffer, 1u, &parsed, &parse_error);
  if (status != 0) {
    switch (parse_error) {
      case ParseError_Empty:
        *out_error = LoadError_Empty;
        break;
      case ParseError_Invalid:
        *out_error = LoadError_Invalid;
        break;
    }
    goto cleanup_error;
  }

  *out_value = parsed;
  free(buffer);
  return 0;

cleanup_error:
  free(buffer);
  return 1;
}

/* 以下のmainは公開ABIを呼ぶC callerであり、上のaltc sourceからは生成されない。 */
int main(void) {
  int32_t value = INT32_C(0);
  LoadError error = LoadError_Allocation;
  int32_t status = load_value(UINT8_C(7), &value, &error);
  return (status == 0 && value == INT32_C(7)) ? 0 : 1;
}
```

## 対応の要点

- `alloc`と`free` annotation自体はruntime valueを作りません。pointer read/writeはannotationではなくmemory access summaryへ推論されます。
- `parse_byte(buffer, 1)?`の`?`は、生成Cのstatus branchとcatchへのerror edgeをcall siteで明示します。
- catchは`ParseError`を公開可能な`LoadError`へ明示変換します。
- successとerrorの両経路で`free`が実行されます。cleanup labelを複製statementへ変えることも可能です。
- `load_value`の`int32_t` status/out signatureは公開ABIです。それ以外のhelper signatureと名前は非規範的です。
