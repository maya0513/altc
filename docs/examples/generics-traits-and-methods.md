# Generic、trait、method

> このCコードは、altcの意味とコストモデルを説明するために推定した非規範的なlowering例です。実装はこの出力形式、内部名、helper、制御構造、最適化、コメント位置、翻訳単位構成を模倣してはならず、Draft規範仕様を満たす別のC11生成を選べます。

関連仕様：[generic、trait、method](../spec/generics-traits-and-methods.md)

## altc

```altc
struct Point {
  x: i32,
  y: i32,
}

trait Equal {
  fn equal(self: *const Self, other: *const Self) -> bool;
}

impl Equal for Point {
  fn equal(self: *const Point, other: *const Point) -> bool {
    self->x == other->x && self->y == other->y
  }
}

impl Point {
  fn translated(self: Point, dx: i32, dy: i32) -> Point {
    Point { x: self.x + dx, y: self.y + dy }
  }
}

fn identity[T](value: T) -> T {
  value
}

fn same[T: Equal](left: *const T, right: *const T) -> bool {
  left.equal(right)
}

@entry
fn main() -> c_int {
  let original = Point { x: 1, y: 2 };
  let moved = original.translated(3, 4);
  let expected = Point { x: 4, y: 6 };
  let value: i32 = identity[i32](7);
  if same[Point](&moved, &expected) && value == 7 { 0 } else { 1 }
}
```

## 取り得るC11

```c
/* Generated by altc. Do not edit. */
#include <stdbool.h>
#include <stdint.h>

typedef struct {
  int32_t x;
  int32_t y;
} Point;

static bool Equal_Point_equal(
    const Point *self,
    const Point *other) {
  return self->x == other->x && self->y == other->y;
}

static Point Point_translated(
    Point self,
    int32_t dx,
    int32_t dy) {
  Point result = { self.x + dx, self.y + dy };
  return result;
}

static int32_t identity_i32(int32_t value) {
  return value;
}

static bool same_Point(
    const Point *left,
    const Point *right) {
  return Equal_Point_equal(left, right);
}

int main(void) {
  Point original = { INT32_C(1), INT32_C(2) };
  Point moved = Point_translated(
      original,
      INT32_C(3),
      INT32_C(4));
  Point expected = { INT32_C(4), INT32_C(6) };
  int32_t value = identity_i32(INT32_C(7));
  return (same_Point(&moved, &expected) &&
          value == INT32_C(7)) ? 0 : 1;
}
```

## 対応の要点

- `identity[i32]`と`same[Point]`は具体型専用functionになります。type descriptorやboxingはありません。
- trait methodは選択済みimplへのstatic callです。table lookupを生成しません。
- `translated`のreceiverはby-valueなので、Cでも`Point` valueを渡します。自動pointer化しません。
- specialized symbol名とinline判断は非規範的です。
