# Dataとpattern

> このCコードは、altcの意味とコストモデルを説明するために推定した非規範的なlowering例です。実装はこの出力形式、内部名、helper、制御構造、最適化、コメント位置、翻訳単位構成を模倣してはならず、Draft規範仕様を満たす別のC11生成を選べます。

関連仕様：[structとenum](../spec/types-and-values.md#struct)、[`match`](../spec/expressions-and-control-flow.md#match)

## altc

```altc
struct Point {
  x: i32,
  y: i32,
}

enum MaybePoint {
  Present(Point),
  Missing,
}

@repr(C)
enum Color {
  Red,
  Green,
  Blue,
}

fn x_or(value: MaybePoint, fallback: i32) -> i32 {
  match value {
    MaybePoint::Present(Point { x, y: _ }) => x,
    MaybePoint::Missing => fallback,
  }
}

fn parse_color(raw: i32) -> Result[Color, i32] {
  match raw {
    0 => Result::Ok(Color::Red),
    1 => Result::Ok(Color::Green),
    2 => Result::Ok(Color::Blue),
    _ => Result::Err(raw),
  }
}

fn option_x(value: Option[Point]) -> i32 {
  match value {
    Option::Some(point) => point.x,
    Option::None => 0,
  }
}
```

## 取り得るC11

```c
/* Generated by altc. Do not edit. */
#include <stdint.h>

typedef struct {
  int32_t x;
  int32_t y;
} Point;

typedef enum {
  MAYBE_POINT_PRESENT,
  MAYBE_POINT_MISSING
} MaybePointTag;

typedef struct {
  MaybePointTag tag;
  union {
    Point present;
  } payload;
} MaybePoint;

typedef enum Color {
  Color_Red,
  Color_Green,
  Color_Blue
} Color;

typedef enum {
  RESULT_COLOR_OK,
  RESULT_COLOR_ERR
} ResultColorTag;

typedef struct {
  ResultColorTag tag;
  union {
    Color ok;
    int32_t err;
  } payload;
} ResultColor;

typedef enum {
  OPTION_POINT_SOME,
  OPTION_POINT_NONE
} OptionPointTag;

typedef struct {
  OptionPointTag tag;
  union {
    Point some;
  } payload;
} OptionPoint;

static int32_t x_or(MaybePoint value, int32_t fallback) {
  switch (value.tag) {
    case MAYBE_POINT_PRESENT:
      return value.payload.present.x;
    case MAYBE_POINT_MISSING:
      return fallback;
  }
  return fallback;
}

static ResultColor parse_color(int32_t raw) {
  ResultColor result;
  switch (raw) {
    case 0:
      result.tag = RESULT_COLOR_OK;
      result.payload.ok = Color_Red;
      break;
    case 1:
      result.tag = RESULT_COLOR_OK;
      result.payload.ok = Color_Green;
      break;
    case 2:
      result.tag = RESULT_COLOR_OK;
      result.payload.ok = Color_Blue;
      break;
    default:
      result.tag = RESULT_COLOR_ERR;
      result.payload.err = raw;
      break;
  }
  return result;
}

static int32_t option_x(OptionPoint value) {
  switch (value.tag) {
    case OPTION_POINT_SOME:
      return value.payload.some.x;
    case OPTION_POINT_NONE:
      return INT32_C(0);
  }
  return INT32_C(0);
}

/* 以下のmainは実行結果を示すC callerであり、上のaltc sourceからは生成されない。 */
int main(void) {
  MaybePoint point = {
    .tag = MAYBE_POINT_PRESENT,
    .payload.present = { INT32_C(7), INT32_C(9) }
  };
  OptionPoint option = {
    .tag = OPTION_POINT_SOME,
    .payload.some = { INT32_C(4), INT32_C(5) }
  };
  ResultColor color = parse_color(INT32_C(1));
  return (x_or(point, INT32_C(-1)) == INT32_C(7) &&
          option_x(option) == INT32_C(4) &&
          color.tag == RESULT_COLOR_OK &&
          color.payload.ok == Color_Green) ? 0 : 1;
}
```

## 対応の要点

- 通常enumのtag width、padding、size、alignmentはimplementation-definedで、union名などのC spellingは非規範的です。
- `@repr(C)`の`Color`だけは対象C ABIのenumとして公開できます。
- `Option`と`Result`は通常のtagged valueです。typed `raise`用の隠れたreturn型ではありません。
- exhaustive checkはaltc側で完了します。生成Cの到達不能fallbackの形は実装裁量です。
