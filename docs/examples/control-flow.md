# 制御フロー

> このCコードは、altcの意味とコストモデルを説明するために推定した非規範的なlowering例です。実装はこの出力形式、内部名、helper、制御構造、最適化、コメント位置、翻訳単位構成を模倣してはならず、Draft規範仕様を満たす別のC11生成を選べます。

関連仕様：[式と制御フロー](../spec/expressions-and-control-flow.md)、[slice](../spec/types-and-values.md#arrayとslice)

## altc

```altc
fn enter(trace_depth: *mut i32) {
  *trace_depth += 1;
}

fn leave(trace_depth: *mut i32) {
  *trace_depth -= 1;
}

fn sum_positive(values: []const i32, trace_depth: *mut i32) -> i32 {
  enter(trace_depth);
  defer {
    leave(trace_depth);
  }

  let mut total: i32 = 0;
  for value in values {
    if value < 0 {
      continue;
    }
    if value == 99 {
      break;
    }
    total += value;
  }
  return total;
}

fn count_to(limit: i32) -> i32 {
  let mut count: i32 = 0;
  while count < limit {
    count += 1;
  }

  let mut checksum: i32 = 0;
  for (let mut i: i32 = 0; i < count; i += 1) {
    checksum += i;
  }
  checksum
}
```

## 取り得るC11

```c
/* Generated by altc. Do not edit. */
#include <stddef.h>
#include <stdint.h>

typedef struct {
  const int32_t *data;
  size_t len;
} I32Slice;

static void enter(int32_t *trace_depth) {
  *trace_depth += INT32_C(1);
}

static void leave(int32_t *trace_depth) {
  *trace_depth -= INT32_C(1);
}

static int32_t sum_positive(
    I32Slice values,
    int32_t *trace_depth) {
  int32_t total = INT32_C(0);
  enter(trace_depth);

  for (size_t index = 0u; index < values.len; ++index) {
    int32_t value = values.data[index];
    if (value < INT32_C(0)) {
      continue;
    }
    if (value == INT32_C(99)) {
      break;
    }
    total += value;
  }

  leave(trace_depth);
  return total;
}

static int32_t count_to(int32_t limit) {
  int32_t count = INT32_C(0);
  while (count < limit) {
    count += INT32_C(1);
  }

  int32_t checksum = INT32_C(0);
  for (int32_t i = INT32_C(0); i < count; i += INT32_C(1)) {
    checksum += i;
  }
  return checksum;
}

/* 以下のmainは実行結果を示すC callerであり、上のaltc sourceからは生成されない。 */
int main(void) {
  const int32_t data[] = {
    INT32_C(1), -INT32_C(2), INT32_C(3), INT32_C(99), INT32_C(100)
  };
  I32Slice view = { data, 5u };
  int32_t trace_depth = INT32_C(0);
  int32_t sum = sum_positive(view, &trace_depth);
  int32_t checksum = count_to(INT32_C(4));
  return (sum == INT32_C(4) &&
          checksum == INT32_C(6) &&
          trace_depth == INT32_C(0)) ? 0 : 1;
}
```

## 対応の要点

- range-forはslice expressionとlengthを一度取得し、値bindingを各iterationでcopyします。
- `continue`と`break`のためのiterator objectやdispatchはありません。
- `defer`はearly returnを含むすべてのexitで必要です。この例ではreturn直前へ展開しています。
- defer bodyはscope退出時に評価され、その時点の`trace_depth` bindingを参照します。この例ではbinding自体を再代入していません。
- trace stateは明示pointerで渡します。read/writeの存在はsignatureを変えず、`indirect-read`と`indirect-write`としてmemory access summaryへ反映されます。
